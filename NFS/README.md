# Визитка для NFC-метки — @yung_pretty_boi

Сайт-визитка под NFC-метку: прикладываешь телефон → открывается эта страница.

```
nfc-portfolio/
├── index.html          ← сама страница (тексты править здесь)
├── styles.css          ← дизайн: стеклянные карточки, бежево-белая палитра
├── script.js           ← «Сохранить контакт» (vCard), копирование номера
├── assets/
│   ├── avatar.jpg      ← аватарка 480×480
│   ├── bg.jpg          ← фон 1024×1536, 308 КБ (используется везде)
│   └── bg-small.jpg    ← облегчённый фон 600×900, 100 КБ (не подключён, см. ниже)
└── README.md
```

**Про фон.** На мобильных кадр поджат, чтобы церковь попадала в верхнюю половину
экрана, стекло сделано чуть прозрачнее — силуэт читается сквозь карточки.
Все настройки в `styles.css`:

```css
.bg{ background-size:cover; background-position:center; }              /* десктоп */
@media (max-width:700px){
  .bg{ background-size:auto 136%; background-position:56% 6%; }        /* мобильный кадр */
  .card{ background:rgba(255,252,246,.40); }                           /* прозрачность стекла */
}
```

Если понадобится экономить трафик, замени в правиле `.bg` путь
`assets/bg.jpg` на `assets/bg-small.jpg` — картинка втрое легче.

**Вариант фона с крупной церковью.** В папке лежит `assets/bg-alt.jpg` — тот же
туманный пейзаж, но храм занимает почти весь кадр, как на исходном скриншоте.
Чтобы включить его, поменяй в `styles.css` в правиле `.bg` путь
`assets/bg.jpg` на `assets/bg-alt.jpg` (и, при желании, на мобильном —
в медиазапросе `max-width:700px`).

## Главное про NFC

В метку **нельзя** записать сайт целиком — в NTAG213 всего ~144 байта памяти,
в NTAG215 ~504 байта, в NTAG216 ~888 байт. Поэтому в метку пишется **короткая
ссылка**, а страница лежит в интернете. Ссылка вида `https://.../` занимает
20–40 байт — влезает в любую метку.

## Шаг 1. Выложить сайт в интернет (бесплатно)

### Вариант A — Netlify Drop (30 секунд, без регистрации)

1. Открой <https://app.netlify.com/drop>
2. Перетащи в окно **всю папку** `nfc-portfolio` (не отдельные файлы).
3. Через пару секунд появится адрес вида `https://random-name-123.netlify.app`.
4. Зарегистрируйся (бесплатно), чтобы адрес не пропал и его можно было переименовать.

### Вариант B — GitHub Pages

1. Создай публичный репозиторий, залей туда файлы из папки `nfc-portfolio`.
2. Settings → Pages → Source: `Deploy from a branch`, ветка `main`, папка `/ (root)`.
3. Адрес будет вида `https://логин.github.io/имя-репозитория/`.

### Вариант C — Cloudflare Pages

Pages → Create project → Upload assets → перетащить папку. Бесплатно, быстрый CDN.

> Домен по желанию: свой домен подключается в панели хостинга в 2–3 клика.
> После публикации пришли мне итоговый адрес — я подставлю его в `og:url`
> и подскажу короткий вариант для метки.

## Шаг 2. Записать метку

### С телефона — приложение NFC Tools

1. Установи **NFC Tools** (iOS / Android), открой вкладку **ЗАПИСЬ** → «Добавить запись».
2. Выбери тип **URL / URI** и вставь адрес сайта (полностью, с `https://`).
3. Нажми «Записать» и приложи метку к телефону — держи до звукового сигнала.
4. Проверь: вкладка **ЧТЕНИЕ** → приложи метку → должна показаться ссылка.

### С компьютера — USB-ридер

Если купишь ридер ACR122U или PN532, скажи — напишу скрипт на Python
(`nfcpy`), который запишет NDEF-запись с этого Mac одной командой.

### Про сами метки

- Бери **NTAG213 / NTAG215 / NTAG216** (NFC Forum Type 2) — они пишутся и перезаписываются.
- Металл глушит NFC: на металлическую поверхность нужны метки «anti-metal» (с ферритовой прокладкой).
- Если метка помечена как **locked / read-only**, перезаписать её уже нельзя.
- iPhone (XS и новее) читает метку со ссылкой **без приложения** — просто приложив к экрану.
- Android читает через встроенное приложение или любым NFC-сканером.

## Что править в текстах

| Что | Где |
|---|---|
| Имя, роль, кнопки | `index.html`, блок `<header class="hero">` |
| Услуги | `index.html`, блок `Чем занимаюсь` |
| Проекты | `index.html`, блок `Проекты` (там есть `TODO`) |
| Телефон, Telegram, vCard | `index.html` + `script.js` (константы `PHONE`, `HANDLE`) |
| Цвета, размытие, радиусы | `styles.css`, блок `:root` вверху файла |
